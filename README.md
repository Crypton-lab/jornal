# Jornal

App para registrar pedidos, propinas, gastos y turnos de reparto. Funciona sin internet y se instala en el celular desde Chrome.

Los datos se guardan solo en el celular. Usa "Copiar respaldo" de vez en cuando y guárdalo en tus notas.

Para publicar cambios: edita `index.html` y sube el número de `VERSION` en `sw.js` (por ejemplo `jornal-v2`).
